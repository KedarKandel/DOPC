# Delivery Order Price Calculator

This application calculates delivery price breakdowns based on cart value, venue location, and user location. The application is built using React, TypeScript, tailwind-css, react-hook-form,and Zod for schema validation.

For testing purpose: vitest, react-testing-library, jest-dom has been utilized.
* copy this venue Slug : "home-assignment-venue-helsinki"


Get started:

1. download/clone from dropbox.

2. cd dopc in the terminal and npm install to install all required dependencies.

3. start the development server:
   command: npm run dev

4. navigate to http://localhost:5173/ in the browser

5. enter the information in the form:
 # venue slug is : "home-assignment-venue-helsinki", it's kept default as well but works with any venue if there is a valid endpoint.
 # get current location from the get location button or enter valid co ordinates yourself.

6. Run the tests : cd into dopc in the terminal
   command: npm run test
